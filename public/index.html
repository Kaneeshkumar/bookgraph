Why Neo4j Over Relational (SQL) Databases?

Feature Relational Database (SQL / RDBMS) Graph Database (Neo4j / Property Graph)
Data Model Flat tables with rows and foreign key columns. Nodes (entities) and directed Relationships (first-class citizens).
Recommendation Query Requires 4 to 6 multi-table JOIN operations (slow as tables grow). Single line Cypher pattern matching using pointer traversal (index-free adjacency).
Traversal Speed O(log N) per join; index lookups required at every step. O(1) pointer dereferencing per relationship hop, independent of total database size.
Schema Flexibility Rigid schema; adding new relationship attributes requires table schema alterations. Dynamic property graphs; relationships can hold arbitrary properties (e.g. stars, status).

20-Mark Viva Preparation Questions & Answers

Q1: What is the core data model in Neo4j and how is it used in BookGraph?

Neo4j uses the Labeled Property Graph (LPG) model. Entities are represented as Nodes with labels (:Student, :Book, :Author, :Genre) and key-value properties. Connections are represented as directed Relationships ([:BORROWED], [:WRITTEN_BY], [:BELONGS_TO], [:RATED]), which are stored as direct pointers on disk.

Q2: How does Collaborative Filtering work in Cypher without complex machine learning?

Collaborative filtering is achieved through simple graph pattern matching: (me:Student)-[:BORROWED]->(shared:Book)<-[:BORROWED]-(peer:Student)-[:BORROWED]->(rec:Book). By filtering out books already borrowed by me (WHERE NOT (me)-[:BORROWED]->(rec)) and grouping by count(DISTINCT peer), the graph naturally ranks books read by students with similar taste.

Q3: What is "Index-Free Adjacency" in Neo4j?

In relational databases, joining two tables requires searching an index (usually a B-tree) to locate matching foreign keys. In Neo4j, each node directly contains physical pointers to its adjacent relationships and connected nodes. Traversal is O(1) per hop, making path finding constant time regardless of how many million records exist.

Q4: How do you connect Neo4j with Node.js in this project?

We use the official neo4j-driver npm package communicating over the binary Bolt Protocol (port 7687). Sessions execute parameterized Cypher queries via session.run(query, params) to prevent Cypher injection and return graph records formatted as JSON for the web UI and Vis.js.

Connecting to Live Neo4j (Free Cloud AuraDB or Desktop):

  1. Create a free cloud Neo4j instance at neo4j.com/cloud/aura-free (or start Neo4j Desktop / Docker).
  2. Copy your connection URI (e.g. neo4j+s://xxxxxx.databases.neo4j.io) and password into the .env file in scratch/bookgraph.
  3. Run npm run seed to automatically populate all books, students, authors, and relationships!
